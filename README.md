A single one-word entry, written by `main.ts` to `/output/entry.txt` — nothing else.

## The word

> Vampire

## Why this word

- **A fresh metaphor:** the small field saturates with hovering machines (Hovercraft five times, Seagull, Helicopter), meeting-compounds (Meetingfarmer, Meetingizer, Meetingivore, Meetingaholic) and circle-back coinages. Nobody reached for the monster.
- **Literally accurate:** it only appears after dark — every message lands at night; it drains the team a little at a time; it must be invited into every meeting; and sunlight (a day off) is a genuine defence.
- **Funny because it is true:** one word, and every employee who has answered a 1 a.m. "quick question" knows exactly which boss it names.
- **Tight:** 7 characters against the 1–30 gate, exactly one word.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
